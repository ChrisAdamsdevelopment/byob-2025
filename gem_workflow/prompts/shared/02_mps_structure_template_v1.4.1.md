# Master Project Specification (MPS) Structure Template v1.4.1

## 1. Objective
- One-line objective statement.

## 2. Primary User / Stakeholder
- Name or role of primary beneficiary/decision-maker.

## 3. Scope
### In Scope
- Bullet list (≥3 items).

### Out of Scope
- Bullet list (≥3 items).

## 4. Constraints
- Time, budget, tooling, compliance constraints.

## 5. Success Metrics
- Measurable targets tied to business or technical outcomes.

## 6. Requirements (REQ-###)
- Table: ID | Statement | Priority | Notes.

## 7. Non-Functional Requirements (NFR-###)
- Table: ID | Statement | Metric | Notes.

## 8. Assumptions (ASSUMP-###)
- Table: ID | Statement | Impact.

## 9. Risks (RISK-###)
- Table: ID | Statement | Mitigation | Owner.

## 10. Decisions (DEC-###)
- Table: ID | Summary | Rationale.

## 11. Open Questions (Q-###)
- Table: ID | Question | Owner.

## 12. Test Plan (TEST-###)
- Mapping: TEST-### -> [REQ-###/NFR-###].

## 13. Milestones (MS-###)
- Table: ID | Milestone | Target Date.
